# CMPT310-Project
This project is an artificial intelligence model that takes in various economic and qualitative factors such as location, pricing, size, income level, nearby amenities, etc., to deliver an investment potential rating. More specifically, it classifies the property as having a high, medium, or low return on investment (ROI).

To run the program:
    
    -If you are using Windows: Simply run the "Calgary_Townhouse_ROI_Predictor_(Windows).bat" in the file explorer.

    -If you are on Mac or Linux: 
        1. Open the terminal 
        2. Navigate to the folder containing "Calgary_Townhouse_ROI_Predictor_(Mac_or_Linux).command" (e.g., cd Documents/CMPT310_Project_Group-14)
        3. Type: chmod +x Calgary_Townhouse_ROI_Predictor_(Mac_or_Linux).command 
        4: In your file browser, execute the "Calgary_Townhouse_ROI_Predictor_(Mac_or_Linux).command" file.
